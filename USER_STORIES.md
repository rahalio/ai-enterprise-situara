# Situara — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Head of operational intelligence

- As an ops intelligence lead, I want each use case’s ingest-to-action latency on a live SLO board, so that we manage value windows not job completion.
- As an ops intelligence lead, I want maturity by chain (Aware vs Predictive vs Proactive), so that investment targets the next stage deliberately.

### Streaming analytics engineer

- As a streaming engineer, I want to register contextual sources and join keys for a chain, so that situational intelligence is reproducible.
- As a streaming engineer, I want feature-parity validation when promoting a lake-trained model to streaming, so that training-serving skew cannot silently ship.
- As a streaming engineer, I want elastic scale policies tied to declared event-rate classes, so that storm or travel peaks do not drop the chain.

### Control-room / NOC operator

- As a control-room operator, I want prescribed work orders with stage explanations, so that I can trust actions during weather events.
- As an operator, I want customer-impacting actions held for approval above a risk threshold, so that automation does not create unsafe or unfair outcomes.
- As an operator, I want automatic safe-mode when model confidence collapses, so that we fall back to known reactive rules.

### Telco marketing ops / fraud analyst

- As a marketing ops manager, I want roaming offers to fire only when situational confidence clears Eurostar-vs-local disambiguation, so that we do not spam highway drivers.
- As a fraud analyst, I want meter under-registration and energy-reversal patterns to open investigation cases with evidence packs, so that grid integrity actions are defensible.

### Platform administrator / model governance

- As a model governor, I want promotion gates from historical training to real-time scoring, so that only reviewed models enter Intelligent Actions.
- As an administrator, I want consent checks enforced before customer messages, so that 1:1 actions remain lawful.
- As an administrator, I want after-action traces exportable for regulators and internal review, so that prescriptions are auditable.
